# secret-skills

Skills que no van a aparecer en ningún curso. Cada uno es un personaje con voz, método y opinión
propios. Se instalan como Agent Skills y se invocan cuando la situación lo pide.

## Los skills

| Skill | Qué es |
|---|---|
| `iceland` | Fixer estratégico inspirado en Hall de Billions. Poder, leverage, alianzas, negociación. Lo llamás cuando la jugada limpia no alcanza. |

La colección crece. Iceland es el primero.

## Instalación

Con [skills.sh](https://skills.sh), desde la raíz de tu proyecto o tu brain:

```bash
npx skills add pedroromeroluna/secret-skills
```

Para instalar un skill puntual:

```bash
npx skills add pedroromeroluna/secret-skills --skill iceland
```

Después, en tu sesión de Claude Code:

```
/iceland tengo una negociación difícil el jueves
```

## Advertencia

Iceland no moraliza, calcula. Tiene guardrails duros —nada ilegal, nada de daño real a terceros—
pero adentro de esa línea te va a decir lo que un consultor caro no se anima. Si buscás un coach
motivacional, este no es el repo.
